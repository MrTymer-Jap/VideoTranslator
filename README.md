# Video Translator — переводчик видео

Локальное GUI-приложение для перевода речи в видео в **субтитры (SRT)** с
возможностью впечатать их прямо в видео. Интерфейс на русском языке, без
вкладок со словарём — пользователю нужно только выбрать видео и языки.

## Что внутри

| Этап | Технология |
|------|------------|
| Интерфейс | **customtkinter** — тёмная современная тема, карточки, статус и прогресс |
| Извлечение аудио | `ffmpeg` (системный или статический бинарник из `imageio-ffmpeg`) |
| Распознавание речи | **faster-whisper** — локально, после загрузки модели; английский, японский и ещё ~90 языков |
| Перевод | **MyMemory API** (основной) + **LibreTranslate** (резервный) — *не Google Translate* |
| Японский словарь | **JMdict с русскими значениями** (69 419 слов) + **Warodai** (97 226 статей, 25 115 слов вне JMdict), оба офлайн; Jisho для английских определений |
| Разбор японского | `fugashi` + UniDic — слова приводятся к нормальной форме перед поиском |
| Субтитры | Генерация `.srt` и вставка в видео через `ffmpeg` |

Словарь работает **внутри** перевода: если онлайн-перевод недоступен или
вернул японский текст без перевода, фрагмент переводится по словарю JMdict на
русский. Вкладка словаря из интерфейса удалена специально: большинство
пользователей не знают японского, им нужен готовый перевод.

### Источники словарей

- **JMdict** — Electronic Dictionary Research and Development Group,
  русские глоссы из проекта [jmdict-simplified](https://github.com/scriptin/jmdict-simplified).
- **Warodai** — [warodai.ru](https://warodai.ru/), лицензия
  [CC BY-NC-ND 3.0](https://creativecommons.org/licenses/by-nc-nd/3.0/).
  Оригинальный файл словаря включается без изменений и разбирается во время
  работы программы; приложение распространяется бесплатно и не вносит
  изменений в сам словарь.

## Установка

Нужен Python 3.10+ (проверено на 3.11).

```powershell
cd D:\AiTranslator
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

`ffmpeg` можно не устанавливать — `imageio-ffmpeg` поставит статический
бинарник автоматически. Если он уже есть в PATH, используется он.

## Запуск

```powershell
python app.py
```

Или просто запустите `run.bat`.

### Готовый exe

Готовый файл можно скачать из релиза:
https://github.com/MrTymer-Jap/VideoTranslator/releases/download/v1.0/VideoTranslator.exe

Или собрать самостоятельно — он находится в `dist\VideoTranslator.exe`
после запуска `build_exe.bat`.

Один файл (~188 МБ): Python, Whisper, ffmpeg, словари и GUI уже внутри —
ничего дополнительно устанавливать не нужно. Первый запуск может занять
20–60 секунд, пока exe распакует компоненты во временную папку.
Для пересборки: `build_exe.bat`.

Проверка собранного exe:

```
VideoTranslator.exe --selftest
```

Отчёт пишется в `%TEMP%\videotranslator_selftest.txt`.

Бета-прогон одного видео без GUI (язык определяется автоматически, цель — русский):

```
VideoTranslator.exe --beta "D:\path\video.mp4" small
```

Рядом с видео сохраняются `.srt` и `.subbed.mp4`, а отчёт —
в `%TEMP%\videotranslator_beta.txt`.

Модель Whisper скачивается при первом переводе (по умолчанию `small`, ~460 МБ).
Можно выбрать `tiny`/`base` для скорости или `medium`/`large-v3` для качества.

## Использование

1. Выберите видео кнопкой **«Обзор»**.
2. Укажите исходный язык (`Автоопределение`, `Английский`, `Японский`, ...) и целевой.
3. Настройте вывод: `.srt` и/или впечатывание в `.subbed.mp4`.
4. Нажмите **«Начать перевод»**.

Результаты сохраняются рядом с видео:

```
movie.srt           — субтитры
movie.subbed.mp4    — видео со встроенными субтитрами (если включено)
```

## Бета-тест (ноябрь 2026)

Прогнаны три коротких ролика с синтезированной речью через собранный exe
(модель `small`, автоопределение языка, перевод на русский):

| Язык | Определение | Результат |
|------|-------------|-----------|
| Английский | `en` | переведён корректно |
| Японский | `ja` | переведён корректно |
| Испанский | `es` | переведён корректно |

Тестовые ролики и отчёты: `tests/beta/`. В ходе теста обнаружен баг: MyMemory
возвращал фрагмент без перевода при финальной точке — исправлено повторным
запросом без пунктуации.

## Важные замечания

- MyMemory бесплатно даёт ~5000 символов в день с одного IP; поле Email в
  настройках увеличивает лимит.
- Качество перевода зависит от длины фрагментов Whisper: короткие
  предложения переводятся точнее.
- Распознавание выполняется локально; наружу отправляется только текст
  фрагментов (на сервисы перевода). Русский словарь JMdict работает офлайн.

## Структура

```
app.py                       GUI (customtkinter)
core/
  audio.py                   извлечение аудио через ffmpeg
  transcribe.py              faster-whisper ASR
  translate.py               MyMemory + LibreTranslate + словарный резерв
  dictionary.py              JMdict (RU), Jisho (EN), fugashi/UniDic
  warodai.py                 парсер словаря Warodai (офлайн-резерв)
  subtitles.py               SRT и впечатывание субтитров
  pipeline.py                оркестрация процесса
dict/jmdict_ru_common.json   JMdict с русскими значениями, 69 419 слов
dict/warodai_txt.zip         Warodai, 97 226 статей (оригинал, CC BY-NC-ND 3.0)
dict/ja_en_mini.json         компактный словарь частых слов
tools/build_dictionary.py    пересборка словаря из jmdict-rus.zip
tools/make_beta_videos.py    генерация тестовых роликов (edge-tts)
VideoTranslator.spec         конфигурация PyInstaller
build_exe.bat                пересборка exe
dist/VideoTranslator.exe     готовый исполняемый файл
requirements.txt
```
